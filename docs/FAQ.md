# 常见问题

[返回首页](../README.md) · [开发文档](DEVELOPMENT.md)

## 没有声音

确认已开始、音量非零且未静音，再检查 Windows 输出设备和对应应用音量。重启后默认不自动发声。

## 快捷键不生效

全局操作需 Ctrl + Alt + 空格、Ctrl + Alt + ↑/↓、Ctrl + Alt + M。其他程序占用时可直接点击，局部快捷键和全局快捷键不同。

## 小条被播放器遮住

普通无边框全屏通常可置顶，独占全屏或播放器自身顶层可能遮挡，切换为窗口全屏后比较。

## 拖动时误操作或找不到窗口

按住并移动超过系统拖动阈值才是拖动，轻点仍执行按钮。右键菜单可回到当前屏幕右上角；先保留设置备份。

## 源码编译后仍需要 .NET

普通 build 与 self-contained publish 不同。使用首页的完整发布命令，下载既有免安装 EXE 则无需另装 .NET。

## 仍无法解决

提交 Issue 时附版本或提交、系统环境、复现步骤与脱敏错误。优先提供合成文件，保留原数据与完整日志的本机备份。
