# 小条节拍器

从仓库的 Releases 下载 `MiniMetronome-v1.2-win-x64.exe`，双击即可运行。适用于 Windows 10 / 11 的 64 位电脑，免安装，无需另装运行环境。完全本地运行，不联网。

## 追剧时怎么用

1. 打开节拍器，设好速度，点击「开始」。
2. 点击右上角的「小条 ↗」。窗口变成约 **180 × 30** 的置顶横条，首次出现在屏幕右上角。尺寸随 Windows 的显示缩放比例变化。
3. 返回视频全屏播放。横条上的 **▶ / Ⅱ** 控制开始或暂停，**− / +** 调整速度，每次 1 BPM。按住 Shift 则每次调整 5 BPM。
4. 鼠标放在小条上滚动滚轮，也能加减速度。
5. 按住小条的任意位置都可以拖动，包括播放键、加减键、速度数字、展开键和空白处。轻点按钮执行原有操作；移动超过系统拖动阈值后，只移动小条，不会误触开关、改变速度或展开窗口。
6. 轻点 **↗** 或速度数字，展开细调；声音会继续播放。

右键小条，可以展开、回到当前屏幕右上角、静音或退出。双击左侧手柄也能展开。关闭窗口才会退出；最小化到任务栏后，声音会继续播放。

## 细调功能

- 速度：20–300 BPM，可输入数值后按 Enter 确认，也可拖动滑块。
- 每小节：1–12 拍；每拍细分：1、2、3、4。
- 可启用首拍重音，选择木质、清脆或电子音色。
- 音量和静音单独控制；静音后仍保留节拍闪烁。
- 「敲击测速」：以目标速度连续点击至少 3 次，自动计算 BPM。
- 大窗口：按住顶部标题或其旁边的空白处拖动，即可移动位置。
- 顶部「置顶」按钮可让大窗口保持在最前方；开启后会高亮显示「已置顶」，再次点击取消。小条始终置顶，展开后会恢复大窗口自己的置顶选择。

## 快捷键

以下快捷键在看视频时也能使用：

| 快捷键 | 操作 |
|---|---|
| Ctrl + Alt + 空格 | 开始 / 暂停 |
| Ctrl + Alt + ↑ / ↓ | 加 / 减 1 BPM |
| Ctrl + Alt + M | 切换小条 / 大窗口 |

节拍器获得焦点时，也可用空格开关、上下键调速。小条中按 Esc 展开。若全局快捷键已被其他软件占用，窗口底部会显示提示，仍可正常点击小条操作。

## 保存和兼容性

会记住速度、拍号、细分、音色、音量、窗口模式和小条位置；下次打开时不会自动发声。设置保存在 `%LOCALAPPDATA%\MiniMetro\settings.json`，删除此文件可恢复默认值。

已检查音频连续输出、不同速度的节拍数量、迷你模式的控制、任意位置拖动与防误触、展开时继续播放，以及小条保持在已激活的无边框全屏窗口上方。普通浏览器或播放器全屏可使用置顶；独占全屏或播放器自身的置顶层可能遮住小条，遇到时改用窗口全屏。

仓库的 `src/` 目录包含 C# / WPF 工程及自动检查程序。可使用 .NET 10 SDK 构建；正常使用只需要 EXE 文件。构建命令见仓库首页。
